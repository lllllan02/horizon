# 知识配图提示词模板

生成位图时使用；矢量绘图也可借此检查设计。先读项目[图文分工](../../../../docs/writing-style.md#图文分工)，查看[认可样图](../assets/diagram-style-reference.png)，从[色板](color-palette.md)选本图需要的颜色。详细风格只在项目规范维护，本模板负责把内容和规范装配成一次可执行请求。

下列占位项按本图填入，将完整提示词暂存到临时目录后调用生成工具。风格统一不意味着布局统一：对象、分支、字段、阅读方向与比例按解释目标选择，不默认复刻样图的左右分栏、工具目录或蓝橙职责。

```text
Use case: infographic-diagram.
Asset type: 中文知识笔记中的辅助解释图。
Primary request: {{读者看完应理解的一个关系或机制，以及本图覆盖范围}}。

Reference images:
- {{项目认可样图的实际路径或输入序号}}：仅风格参考。迁移对象造型、轮廓、局部淡彩、文字层级与视觉分量，不复制它的内容或布局。
- {{存在语义参考时填写路径或输入序号；没有则删去}}：仅内容／关系参考，说明必须保留的语义。

Style:
采用项目默认的克制二维技术编辑插画。{{依据当前图文分工规范补入适用于本图的风格要求与避免项}}。
Palette: {{选取的色值，以及每种颜色在本图表达的含义}}。
Aspect: {{由内容与阅读位置决定的比例}}。
Canvas target: {{目标宽 px}} × {{目标高 px}}；与上述比例一致，按内容量选择紧凑画布，不沿用参考图尺寸。
Intended display: 正文中约 {{显示宽度 px}} 宽，高度按比例；标签须在这一显示尺寸下清楚可读。此项是阅读设计约束，不是要求把显示尺寸文字画进图片。

Objects and relationships:
{{必须出现的实际对象、必要内部组成、包含关系、连接方向和条件；用具体内容代替空泛的步骤名}}。
Semantic invariants: {{最容易被画错、混淆或遗漏的关系和边界}}。
Evidence and conditions: {{本图必需的条件及其标注位置；使用数字时同时列出单位、比较条件及依据，没有相关内容时删去。避免将有条件的收益画成普遍保证}}。
Analogy mapping, if used: {{类比对象的动作、约束和结果分别对应什么，哪里开始不再成立；未使用类比时删去}}。

Composition:
{{适合本图的阅读主线、区域比例、对象变化与连接位置；先确定关系再安排形状}}。
{{说明哪些对象需要简化造型，哪些信息适合文字，哪些内容不在本图范围内}}。
只留对象间必要间距与适量边缘留白；内容少时收紧画布，不用巨大标题、放大图形或空白区域填充版面。

Text, verbatim:
{{逐项列出必须准确呈现的标题、对象名、短标签、字段及必要条件}}。
保持中文清楚、标签贴近对象；不添加未列出的概述段、总结面板或宣传文案。

Validation priorities:
{{本图必须检查的正常路径、分支、方向、归属与状态变化}}。
对照内容依据检查数字、条件与取舍，确认删减和视觉类比没有改变核心判断；上述设计说明仅作生成约束，不自动画成说明面板。
同时对照风格参考检查形象感、色彩面积、线条与标题分量；按预计显示宽度检查标签大小和画面密度，输出完整成图。
```

只传风格样图时也须在提示词中独立写清本图的内容与关系；不能让生成器从样图猜测业务。首次使用本地参考图前先查看图片，调用工具时显式传入参考图。位图中文字或关系有误时修正提示词并重新生成，不通过代码覆盖修补。比较期间将候选暂存在临时目录，最终按[附件留存规则](../../../../docs/metadata-and-links.md#附件留存)处理。
