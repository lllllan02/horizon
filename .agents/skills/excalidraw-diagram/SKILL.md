# 知识配图

用最简短的请求完成内容理解、视觉设计、绘制和验收。用户提供内容即可，不要求其选择图表类型、描述坐标或复制提示词。基于 [coleam00/excalidraw-diagram-skill](https://github.com/coleam00/excalidraw-diagram-skill) 适配；上游方法保存在 [upstream-skill.md](references/upstream-skill.md)，本入口中的中文工作流与渲染方式优先。

## 从短句直接开始

- “把这个画一下”“配张图”：优先取本轮明确指向的文字、文件或上一段讨论；默认生成一张中文解释图，采用项目默认画风，按下节选择交付形式。
- “看不清”“太复杂”“这两块关系不明显”：结合已有图做针对性修改，不要求用户给出设计方案。
- 仅当缺少绘制对象或歧义会改变核心含义时，问一个简短问题。内容足够时直接交付首版，不先让用户审批提纲或选择样式。
- 遵守当前项目的内容、附件与写作规则。请求画图不等于要求改写原笔记、整理知识库或发布；默认交付独立文件，用户要求插入笔记时再维护图片引用。

## 先决定图要解释什么

遵循项目[图文分工](../../../docs/writing-style.md#图文分工)判断配图范围与表达方式：子文突出局部机制，专题入口可串联各分支的整体关系；按该节核对对象变化、方向一致、行列职责与重复展示。调整旧图时先辨认必须保留的解释作用，例如阈值分界或消息保留范围。

内部提炼一句阅读目标：看完图，用户应理解哪个关系或机制？按图文分工先梳理核心判断、对象关系或变化与必要条件，将它们映射到构图及提示词；成图后对照检查简化是否改变含义。避免逐句装进相同方框，也不为了丰富画面补出没有依据的组件。

让位置和图形承担解释：分工可用区域，归属可用嵌套，过程变化可用阶段快照，对比可用并排结构，反馈可用循环。它们是可组合的选择，不是必选模板。简单内容不强加执行边界、代码样例或多层结构；具体协议/API 图才按需核实真实字段和术语，示例须标明是假设。

关系、方向和条件优先于装饰；减少不必要文字，同时保留主链路、重要分支与边界。原文字已经足够时可以说明配图收益有限，但用户明确要图仍先完成合理样图。

## 绘制与交付

1. 按[默认风格与图文分工](../../../docs/writing-style.md#图文分工)设计，查看[认可样图](assets/diagram-style-reference.png)，读取 [color-palette.md](references/color-palette.md)。样图只提供视觉基准，不能直接套用其业务、布局或字段；每张图仍先确定解释目标。
2. 选择实现方式：需要严格控制字段、连接或可编辑交付时用 Excalidraw；需要达到样图的对象造型、自然轮廓和插画感时，配合当前可用的 imagegen Skill 与内置工具生成。用户未指定格式时依据内容判断，不把位图称为可编辑图，也不因使用矢量工具退回纯框线图。
3. 按项目[尺寸要求](../../../docs/writing-style.md#图文分工)，先选画布目标长宽（px）与正文显示宽度，再绘制。生成位图时，按[提示词模板](references/illustration-prompt.md)填入本图内容、关系及尺寸，先保存完整提示词，再将样图作为「仅风格参考」传给 imagegen。工具有尺寸参数时使用其支持的值；只有提示词可用时明确写出目标长宽、比例与紧凑布局，生成后读取实际尺寸，不把提示词要求当作精确输出保证，也不为尺寸控制切换未获授权的生成方式。语义参考与风格参考分别说明；文字或连线有误时重新生成，不用代码覆盖修补位图。用户已授权试画或生成时，直接执行，不重复要求选择风格。
4. 绘制矢量图时，读 [element-templates.md](references/element-templates.md)，需要复杂构图时再读上游方法。生成 `.excalidraw`，用 [rendering.md](references/rendering.md) 导出 PNG 与 SVG；留足中文宽度，保留源文件，不用截图或未渲染的 JSON 代替完成品。
5. 打开成图，检查文字裁切、重叠、连线落点、方向、颜色含义与阅读顺序，再与样图对照对象造型、色彩面积、标题和线条分量。同时在预计显示宽度下查看，检查实际长宽、画布空白与标签可读性；内容少却画布庞大时收紧构图，需要较高源图分辨率时也单独限制显示宽度。关系清楚、画面形象且克制后停止；有问题按实际生成方式修改并重新查看。
6. 在回复中展示图片。矢量图给可编辑源文件，位图给图片与提示词；按项目或当前请求的保存范围交付，不把试稿自动插入正文。获准插入笔记时，按[附件语法](../../../docs/metadata-and-links.md#链接与合并)设置单图显示宽度，并在文档中查看实际占位、缩放比例及窄屏收缩，不能仅凭源图预览宣称排版已验收。未完成目视检查时如实说明，不宣称验证通过。

用户说“再简洁一点”时减少次要文字与装饰；说“这部分没看懂”时优先重组对应关系，必要时补一张局部图。无需每次让用户重复以上要求。
