**「Voyager 将可复用程序存入技能库，让后续任务组合已有行为。」** Wang 等人的 2023 年论文研究 Minecraft 中的持续探索；本篇节选 v2 第 2—3 节的技能形成与复用，不展开完整课程策略，未复现实验。

## 怎样从一次执行形成技能？

自动课程根据当前状态提出任务。模型获得控制 API、已有技能、环境状态和上一轮反馈，生成 JavaScript 程序，再通过 Mineflayer 执行。

反馈包括环境进展、解释器错误和模型根据任务与状态作出的成功判断。未成功时继续修订；通过成功检查后，程序加入技能库，并用自然语言描述的向量作为检索入口。

下一次先依据任务建议和环境反馈找相关技能，将代码作为生成新程序的上下文。记忆保存的是可以调用、组合的动作，因此减少了重新生成已知步骤的需要；模型参数没有因此更新。

## 什么证据支持复用？

论文比较探索进展、技术树和新世界中的未见任务，并设置去掉技能库的消融。在其测试中，技能库帮助复杂任务，也改善了接入同一技能库的 AutoGPT 基线，说明已有程序具有跨运行复用价值。

这些结果建立在特定游戏、控制 API 和少量重复实验上。成功检查包含模型判断，不能当作形式化验证；游戏程序也不能直接移植到任意工具环境。

用于工程 Agent 时，可借鉴**「执行反馈 → 验证 → 保存 → 按条件复用」**，但**「依赖、权限、输入契约及回归检查需要应用自己补齐」**。技能命中只提供候选做法，不自动授予执行权限。
