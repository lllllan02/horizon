本页保留 Go 后端与 AI 服务都需要的公共工程问题，语言机制归 [[go-interview-index|Go 目录]]。编号对应本页来源表；问题围绕社招场景重写，不表示某公司的固定考题。

## 操作系统与网络

- **B01**：进程与线程分别隔离和共享哪些资源？通信与上下文切换的代价有什么不同？（B1）
- **B02**：虚拟地址怎样映射到物理内存？缺页、写时复制与内存占用的关系是什么？（B1）
- **B03**：select、poll 与 epoll 分别怎样等待 I/O？连接多时瓶颈可能出现在哪里？（B1、B5）
- **B04**：哪些资源等待会形成死锁？怎样区分死锁、竞争与普通阻塞？（B1）
- **B05**：TCP 建连与断连为什么需要不同的交互？TIME_WAIT 和 CLOSE_WAIT 分别说明什么？（B2）
- **B06**：TCP 如何处理丢包、乱序与接收端变慢？流量控制和拥塞控制有什么区别？（B2）
- **B07**：HTTP 各版本怎样复用连接和传输请求？升级版本是否能消除所有队头阻塞？（B2）
- **B08**：HTTPS 怎样协商密钥并认证服务端？握手成本怎样影响连接复用？（B2）
- **B09**：已有 HTTP 时为何仍使用 RPC 框架？协议、序列化与服务治理分别属于哪一层？（B2，补充职责边界）

## MySQL

- **B10**：一条查询从连接进入到返回结果会经过哪些环节？怎样定位慢在哪一段？（B3）
- **B11**：B+ 树、聚簇与二级索引怎样影响查询成本？什么时候需要回表？（B3、B5）
- **B12**：联合索引怎样匹配过滤与排序？如何用执行计划核对索引是否真正有效？（B3、B5）
- **B13**：事务隔离与 MVCC 怎样配合？不同读法下的可见性和幻读边界是什么？（B3、B5）
- **B14**：更新或范围查询会锁住什么？索引与查询条件怎样改变锁的范围？（B3）
- **B15**：出现数据库死锁或长时间锁等待时，怎样定位参与事务和加锁顺序？（B3）
- **B16**：undo、redo 与 binlog 各自记录什么？它们怎样参与回滚、恢复与复制？（B3）
- **B17**：Buffer Pool 怎样参与读写？脏页何时落盘，为什么修改后不立即写盘？（B3）
- **B18**：分页越往后为什么可能越慢？不同分页方式各自需要什么业务条件？（B3）

## Redis 与缓存

- **B19**：如何按访问模式选择 Redis 数据类型？底层编码变化会怎样影响成本？（B4、B5）
- **B20**：Redis 的命令执行与网络 I/O 怎样分工？「单线程」应该限定到哪部分？（B4、B5）
- **B21**：过期清理与内存淘汰各自在什么条件下触发？如何选择淘汰策略？（B4）
- **B22**：快照与追加日志怎样影响恢复时间、资源占用和可接受的数据损失？（B4、B5）
- **B23**：复制与故障切换怎样协作？为什么切换成功仍可能丢失已确认的写入？（B4）
- **B24**：分片扩容与单 key 热点分别怎样处理？Cluster 扩容为什么不一定解决热点？（B4）
- **B25**：缓存未命中、热点过期与缓存整体不可用分别会怎样冲击下游？怎样区分治理？（B4）
- **B26**：缓存与数据库更新交错或部分失败时，会出现哪些旧值回填路径？怎样恢复一致性？（B4、B5）

## 消息、分布式与服务治理

- **B27**：业务已经提交但响应或确认丢失时，重试怎样避免重复副作用？幂等记录应与什么一起提交？（B8，归并为通用业务题）
- **B28**：消息从生产到业务提交，哪些失败窗口会导致丢失或重复？收到 ACK 能证明什么？（B6）
- **B29**：消息顺序应按什么业务范围保证？分区和消费者并发怎样影响顺序？（B5、B6）
- **B30**：消费积压时怎样区分分区不足、处理变慢与反复重试？扩消费者何时无效？（B6）
- **B31**：分布式锁怎样应对持有者暂停、租约到期与切主？锁与业务幂等分别保证什么？（B4，补充失败条件）
- **B32**：下游超时或配额不足时，怎样组合限流、排队、重试和降级？如何防止重试放大负载？（B7、B8，按服务调用场景归并）
- **B33**：日志、指标与 Trace 各能回答什么问题？跨服务调用怎样关联一次请求？（B5）
- **B34**：接口尾延迟上升时怎样区分 CPU、I/O、锁等待与下游慢？应先采集哪些证据？（B6，迁移为语言无关排障题）

## 系统设计与编码

- **B35**：给定访问量与有效期，怎样设计短链接服务的标识、存储、查询与扩容？（B5、B7）
- **B36**：突发秒杀流量下如何扣库存并处理重复请求、超时和部分失败？（B5）
- **B37**：关注关系和信息流怎样建模？读写比例与热点用户会怎样改变方案？（B5、B7）
- **B38**：如何给一个已有单机服务制定扩容与高可用方案，并说明一致性、成本和故障边界？（B5、B7）
- **B39**：怎样实现 LRU 缓存，并说明查询、更新和淘汰的复杂度？（B7）
- **B40**：怎样求滑动窗口最大值？输入规模变化时，时间与空间成本怎样判断？（B5）
