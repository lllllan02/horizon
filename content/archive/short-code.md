**短码（Short Code）是短链接系统中用于标识一条网址映射的简短字符串，服务端用它查找目标 URL。** 例如，`https://s.example/aB12x` 中的 `aB12x` 就是短码。同一命名范围内，短码应唯一；同一个目标 URL 则可以对应多个短码。

常见生成方式有两种：

- 将唯一整数 ID 编为 [[base62|Base62]] 字符串：约定编码规则后可保持唯一，但连续 ID 生成的短码可能被推测和枚举。
- 随机生成字符串：需要足够的随机空间，并用唯一约束检测、处理碰撞；仅使用字母和数字不代表已经具备不可预测性。

短码负责标识，[[short-links|短链接]]则是包含域名和短码、可供用户访问的完整网址。
