**长期记忆除用户隔离、权限和敏感信息保护外，还需防止不可信内容被长期保存，以及敏感信息在不合适的场景被召回。** 本地文件同样需要保护。

- 记忆污染：把错误内容或工具返回中的恶意指令保存为可信事实或执行规则，持续影响后续行为。
- 不当[[agent-memory#检索与使用|召回]]：即使属于同一用户，也可能在共享输出等不合适的场景暴露敏感信息。

记忆需要保留来源与信任边界；外部内容不能仅因被保存就升级为操作授权。删除也应处理相关索引和缓存，避免已删除内容再次被召回。
