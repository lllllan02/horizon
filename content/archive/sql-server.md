**SQL Server（Microsoft SQL Server）是微软开发的[[relational-database|关系型数据库]]管理系统，用于企业数据存储、事务处理和数据分析，与 .NET、Azure 等微软技术生态集成紧密。** 它提供商业版本，也提供面向特定用途的免费版本。

它的主要能力包括：

- 事务与并发：支持 ACID [[transaction|事务]]，通过事务日志、锁和可配置的行版本控制协调并发访问。
- 查询与分析：使用 T-SQL 查询和编程，支持[[database-index|索引]]、查询优化器及列存储索引，可结合配套工具完成数据集成、分析和报表。
- 高可用与恢复：提供 Always On 可用性组、故障转移群集实例、备份与恢复等能力。
- 部署与集成：数据库引擎可运行于 Windows 和 Linux，也可部署在 Azure 等云环境；不同平台和版本的功能范围有所不同。

参考：[SQL Server 官方介绍](https://learn.microsoft.com/sql/sql-server/what-is-sql-server)、[Linux 上的可用性组](https://learn.microsoft.com/en-us/sql/linux/sql-server-linux-availability-group-overview)。
