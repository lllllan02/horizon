本页围绕应用开发、执行可靠性与项目取舍合并题目，不展开模型训练研究。括号内为本页来源编号；一般服务调用与业务幂等复用[[backend-interview-index#消息、分布式与服务治理|后端公共题]]，不另存同义题。

## 模型调用与上下文基础

- **A01**：Token 与上下文窗口怎样限制输入输出？如何估算一次任务的预算？（A1）
- **A02**：温度、Top-K 与 Top-P 分别改变什么？哪些任务需要怎样的输出稳定性？（A2）
- **A03**：提示词、RAG 与微调各适合改变什么能力？面对企业知识需求怎样选择？（A2）
- **A04**：怎样取得结构化输出并校验字段与业务约束？格式正确但内容无效时怎么办？（A1、A2）
- **A05**：系统指令、用户消息与工具结果怎样组织？历史消息丢失或角色混用会影响什么？（A2）
- **A06**：怎样为不同任务选择或路由模型？质量、延迟与费用之间如何比较？（A1）

## RAG 与知识库

- **A07**：从原始文档到回答，需要哪些数据处理与检索步骤？每一步的输入输出是什么？（A3）
- **A08**：切块大小、重叠和文档结构怎样影响证据完整性与检索噪声？（A3）
- **A09**：怎样选择 Embedding 并更换索引版本？迁移期间如何检查召回是否退化？（A2）
- **A10**：关键词与向量召回各容易遗漏什么？如何融合排序，为什么不直接相加分数？（A3）
- **A11**：重排改变候选中的什么信息？召回阶段没找到证据时，它能否补救？（A3）
- **A12**：多轮追问和复杂问题怎样改写或拆分查询？何时值得增加额外检索步骤？（A2）
- **A13**：答案错误时怎样区分解析、召回、重排、上下文拼接与生成问题？（A3）
- **A14**：资料更新、删除后怎样同步索引与缓存？如何发现检索仍在使用旧证据？（A2）
- **A15**：用户与租户权限应该在哪个检索阶段检查？怎样避免越权证据进入模型上下文？（A1、A3）

## Agent 执行与工具集成

- **A16**：什么时候需要模型决定下一步，什么时候固定工作流更合适？怎样组合两者？（A4、A1）
- **A17**：逐步行动与先规划再执行各有什么适用条件？中途发现计划错误时怎样调整？（A4）
- **A18**：如何判定任务完成、停滞或失控？循环次数、时间与费用边界由谁执行？（A4）
- **A19**：模型之外的 Harness、框架与运行时分别管理什么？哪些行为需要程序保证？（A4）
- **A20**：工具名称、描述和参数怎样设计，才能减少误选与错误参数？（A1、A4）
- **A21**：一次工具调用从模型请求到结果反馈怎样完成？执行错误应该怎样返回给模型？（A4）
- **A22**：怎样判断工具调用之间的依赖？并行结果如何汇总和处理局部失败？（A1、A4）
- **A23**：MCP 与模型的工具调用分别负责什么？接入 MCP 后，模型侧的调用流程改变在哪里？（A1、A2）
- **A24**：MCP 的 Tools、Resources 与 Prompts 分别怎样提供能力，应该按什么条件选择？（A2）
- **A25**：本地与远程 MCP 连接各需要处理哪些生命周期、身份和权限问题？（A1、A2）
- **A26**：什么时候单 Agent 不够用？多 Agent 的任务分配、通信与共享状态怎样设计？（A4）
- **A27**：Agent 交接任务时传递哪些上下文和结果？怎样避免信息丢失或相互污染？（A4）

## 记忆、状态与恢复

- **A28**：当前上下文、任务状态和长期记忆分别保存什么？它们与知识检索有什么区别？（A2、A4）
- **A29**：哪些信息值得写入长期记忆？如何处理重复、冲突与用户改口？（A1、A4）
- **A30**：怎样按当前任务检索记忆？相似度、时效和任务相关性如何影响取舍？（A1、A4）
- **A31**：上下文压缩时应保留哪些约束与进度？怎样检查摘要没有改变后续任务？（A4）
- **A32**：长任务中断后怎样恢复模型执行状态，同时核对工具副作用是否已经发生？（A5）

## 评测与可观测性

- **A33**：怎样定义 Agent 成功？最终结果、过程约束与资源消耗应怎样分别验收？（A6）
- **A34**：怎样构建含失败与边界场景的任务集，并隔离调试数据与最终验证数据？（A6）
- **A35**：检索相关性、排序质量、回答正确性与证据支持度应怎样分别衡量？（A3、A6）
- **A36**：至少一次成功与多次全部成功分别说明什么？重复运行应该怎样报告？（A6）
- **A37**：哪些判断适合交给模型裁判？如何用人工样本检查偏差与误判？（A6）
- **A38**：怎样沿一次任务轨迹定位首次偏离？工具指标与端到端成功率怎样结合？（A6）

## 安全、性能与上线场景

- **A39**：一次 Agent 任务越来越慢、越来越贵时，如何区分上下文、调用轮次、缓存和模型选择的问题？（A1）
- **A40**：外部文档或工具结果携带恶意指令时，怎样限制它们影响模型和执行流程？（A4）
- **A41**：工具权限、代码沙箱与人工审核分别放在哪里？如何约束模型出错后的影响范围？（A4）
- **A42**：怎样设计结合知识问答、业务工具与人工转接的客服系统，并验证各环节协作？（A2）
- **A43**：流式回复怎样处理客户端断开、主动停止与重新连接？服务端任务和历史结果如何对应？（A2；Go 取消机制归 G23）
- **A44**：文件解析与建索引怎样组织为可追踪的异步任务？批量失败或重复提交时怎样恢复？（A2；业务幂等归 B27）
- **A45**：Prompt、工具或模型更新后怎样回归、灰度与回滚？已有会话和长期状态如何处理？（A4、A6，合并上线追问）
- **A46**：自然语言查数据库时怎样限制查询范围与权限，并核对生成 SQL 的结果？（A1）
- **A47**：编码 Agent 如何获取代码上下文、修改文件并验证结果？执行代码的边界怎样限定？（A1）
