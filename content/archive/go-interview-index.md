以下按考点合并 Go 题目，只保留问法。括号内为本页来源编号；涉及 map、切片增长、调度与 GC 的实现问题，作答时需要明确 Go 版本。

## 数据结构与值语义

- **G01**：数组与切片在复制、传参时分别复制什么？修改元素或追加元素会怎样影响原数据？（G1、G3）
- **G02**：切片容量不足时如何扩容？为什么不能把增长倍率写成跨版本固定规则？（G1）
- **G03**：map 如何定位键、处理冲突与扩容？源码版本变化会影响哪些解释？（G1）
- **G04**：哪些类型可以作为 map 的键？浮点数作为键时有哪些容易误判的情况？（G1）
- **G05**：map 遍历顺序有哪些保证？迭代期间新增或删除元素时，遍历结果怎样理解？（G1）
- **G06**：为什么不能直接取得 map 元素的地址？需要修改元素内部字段时怎样设计存储值？（G1，补充使用场景）
- **G07**：多个 goroutine 共享 map 时怎样保证安全？什么场景选择加锁、分片或 sync.Map？（G2、G3）
- **G08**：string 与 []byte 相互转换时何时复制数据？减少复制需要承担什么限制？（G2）

## 接口、反射与错误处理

- **G09**：为什么装入 nil 指针的接口仍可能不等于 nil？这会怎样影响 error 返回值？（G1、G3）
- **G10**：值接收者与指针接收者怎样影响方法集合和接口实现？（G1）
- **G11**：类型转换与类型断言解决什么问题？断言失败时有哪些处理方式？（G1）
- **G12**：反射怎样取得和修改运行时的值？哪些条件会限制它的使用？（G1）
- **G13**：defer 的参数求值、调用顺序与函数返回怎样配合？命名返回值会带来什么差异？（G3）
- **G14**：panic 如何传播，recover 在哪里调用才有效？goroutine 边界怎样影响恢复？（G2、G3）
- **G15**：错误包装后如何判断错误类型与来源？errors.Is、errors.As 分别用来判断什么？（G3）

## 并发与生命周期

- **G16**：带缓冲与无缓冲 channel 的收发何时阻塞？它们怎样实现 goroutine 间协调？（G1、G3）
- **G17**：nil、正常与已关闭 channel 在收发和关闭时分别怎样表现？（G1、G2）
- **G18**：多个发送者共享 channel 时由谁关闭？如何避免重复关闭和发送、关闭的竞争？（G1）
- **G19**：select 在多个分支就绪、全部阻塞或存在 nil channel 时怎样选择？（G1，按 channel 场景改写）
- **G20**：WaitGroup 如何协调任务完成？怎样给等待过程增加超时，并处理超时后仍在执行的任务？（G2）
- **G21**：sync.Once 怎样约束初始化次数？初始化失败或 panic 后，后续调用应该如何理解？（G3）
- **G22**：sync.Pool 适合复用什么对象？为什么不能用它保证连接或缓存项长期存在？（G3）
- **G23**：context 的取消、截止时间与 Value 怎样传播？取消通知与任务真正退出是什么关系？（G1、G3）

## 调度、内存与排障

- **G24**：goroutine 与操作系统线程在资源、调度和阻塞方面有什么区别？（G1）
- **G25**：G、M、P 如何配合执行任务？本地队列、全局队列与工作窃取解决什么问题？（G1、G2、G3）
- **G26**：goroutine 在哪些时机让出或被抢占？系统调用阻塞时，其他任务怎样继续执行？（G1）
- **G27**：Go 怎样判定对象仍然存活？并发标记、写屏障、暂停阶段与 GC 参数怎样关联？（G1、G3）
- **G28**：哪些因素会使对象逃逸到堆上？怎样用编译器信息核对，而不是只凭代码形式判断？（G1、G2、G3）
- **G29**：内存持续增长时如何区分对象滞留与 goroutine 泄漏？HTTP 调用中应检查哪些资源生命周期？（G2）

## Go 编码练习

- **G30**：如何让两个 goroutine 按顺序交替输出？退出与异常时怎样避免互相等待？（G2，补充退出条件）
- **G31**：怎样实现支持阻塞读取的并发 map？键不存在、等待超时与并发写入时分别怎样处理？（G2）
- **G32**：怎样并发查询一个切片并在找到目标后结束工作？取消与等待任务完成怎样配合？（G2，补充生命周期条件）
