**Agent 按需加载是一种按当前任务需要，将资料、指令或工具定义逐步提供给模型的机制。** 尚未用到的内容保存在文件、数据库或工具目录中，模型先看到必要内容与发现入口。

一次带入全部文档、历史和工具说明，会占用有限的上下文，也增加无关信息。按需加载让当前输入更聚焦，同时保留取回细节的能力；减少的是本轮输入量，原始存储量不一定减少。

## 加载对象

| 对象 | 先提供 | 按需补充 |
| --- | --- | --- |
| [[context-loading\|文档、代码、旧历史与工具结果]] | 目录、摘要、预览与原文位置 | 相关章节、函数、日志或原始约定 |
| [[agent-memory#检索与使用\|长期记忆]] | 必要的核心偏好与查询入口 | 适用于当前用户、任务且仍有效的记录 |
| [[tool-loading\|工具定义]] | 常用工具与发现入口 | 匹配工具的用途、参数与约束 |
| [[anthropic-agent-skills-summary\|Skill 指令与资源]] | 名称、描述与适用场景 | `SKILL.md`，以及用到的附属资料或脚本 |

资料提供证据，工具定义说明调用方式，Skill 提供操作方法。工具定义与执行结果属于不同对象：前者供模型生成调用，后者提供执行后取得的信息。

## 加载方式

- 直接读取：入口已给出文件路径、记录 ID 或章节位置时，模型调用文件读取、按 ID 查询等工具，取得相关部分。
- 检索后读取：位置未知时，提供文件搜索、关键词或语义检索工具；模型先找候选，再读取所需内容。RAG 可用于检索资料，工具搜索则返回匹配工具的用途与参数定义。
- 程序按条件提供：程序根据任务阶段或运行状态，在调用模型前补充对应内容，例如进入发布阶段时加载发布规范，无须每次都由模型主动搜索。

这些方式可以配合使用。Skill 从名称与描述展开到 `SKILL.md`，再读取对应附件，就是利用文件入口逐层展开的「渐进式披露（Progressive Disclosure）」。

## 完整流程

1. 准备入口：程序保存完整内容，先向模型提供目标、必要约束，以及内容的用途、位置或检索工具。
2. 判断需要：模型在执行中识别缺少的证据、方法或调用能力；已知阶段必需的内容也可由程序直接选出。
3. 获取并注入：程序执行搜索或读取，将相关内容及来源、范围加入后续模型输入；工具定义通过相应接口提供。
4. 继续任务：模型利用新内容推理或生成工具调用；仍有缺口就继续检索或补读，内容足够时停止加载。未找到必要内容时，应说明缺口。

**「必要约束与发现入口应保持可见」。** Agent 若不知道仓库有发布规范，就可能根本不去找。按需加载也会增加查找、等待与遗漏风险；已知必需且较小的内容可直接提供，取回内容仍受[[context-budget|上下文预算]]约束。加载资料、Skill 或工具定义本身不构成用户授权。
