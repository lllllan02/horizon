### kanzhun职位描述

- Golang

岗位职责  
BOSS直聘负责 AI Agent 产品及基础设施研发，围绕 Agent 运行时、模型网关、工具调用、Skill/Plugin/MCP ⽣态、桌⾯端、多消息渠道和沙箱环境，建设可稳定交付、可观测、可扩展的⽣产级 Agent 平台。  
1\. 负责 Agent 核心能力建设，包括会话⽣命周期、上下文管理、流式响应、工具调用、多步骤任务、任务中断与恢复、人工审批等。  
2\. 设计并实现 Skill、Plugin、MCP Server 等扩展机制，完善工具定义、权限边界、配置管理、版本管理和分发流程。  
3\. 参与模型网关研发，支持 OpenAI 兼容协议、多模型供应商适配、动态路由、鉴权、额度校验、计费、流式转发及异常处理。  
4\. 参与StyleWork Web/桌面端研发，打通 Agent 会话、执行计划、权限请求、文件产物、调试信息等完整用户工作流。  
5\. 建设本地及远程 Agent 运行环境，包括进程编排、Sidecar 生命周期、工作区路由、文件访问和 Docker/Kubernetes 沙箱隔离。  
6\. 建设微信、飞书、钉钉等消息渠道接入能力，处理身份映射、消息持久化、重试、幂等和多端状态同步。  
7\. 完善 Agent 可观测体系，包括日志、指标、Trace、Token/成本统计、模型调用链路和线上问题诊断。  
8\. 建立单元测试、集成测试和端到端测试，保障 Agent 在模型波动、工具失败、网络中断等情况下的稳定性。  
9\. 参与技术方案、接口协议和工程规范制定，与产品及其他研发共同完成需求拆解和交付。  
岗位要求（硬性）  
1\. 计算机相关专业本科及以上学历，或具备可证明的同等工程能力。  
2\. 3 年及以上软件研发经验，至少有一个真实用户使用的 LLM/Agent 项目落地经验。  
3\. 熟练掌握 Go 和 TypeScript/Node.js，能够独立完成后端服务开发，并具备基本的 React 前端交付能力。  
4\. 熟悉主流大模型 API，理解 Streaming、Tool Calling、Structured Output、Token、上下文窗口及模型限流机制。  
5\. 具备生产级 Agent 工程经验，不局限于 Prompt 编写，能够处理会话状态、工具执行、权限审批、失败恢复和人工介入。  
6\. 熟悉 REST、SSE 或 WebSocket，掌握鉴权、并发控制、超时、重试、幂等和错误治理。  
7\. 具备 MySQL、Redis、SQLite 等存储系统的实际使用经验，能够完成数据模型和持久化方案设计。  
8\. 熟悉 Linux、Git、Docker 及基本 CI/CD 流程，能够独立定位跨进程、跨服务和网络链路问题。  
9\. 具备良好的测试意识，能够为关键逻辑编写单元测试、集成测试和必要的端到端测试。  
10\. 具备基本安全意识，理解最小权限、密钥保护、输入校验、沙箱隔离和敏感信息脱敏。  
11\. 能够阅读英文技术文档及开源项目源码，具备清晰的技术沟通和文档表达能力。  
岗位要求（加分项）  
1\. 深度使用或参与过 OpenCode、Codex、Claude Code、OpenAI Agents SDK、LangGraph、AutoGen 等 Agent 框架。  
2\. 有 MCP、Skill、Plugin、Computer Use、Browser Automation 或多 Agent 协作系统开发经验。  
3\. 熟悉 Electron、桌面端进程通信、跨平台打包及本地运行时管理。  
4\. 有模型网关、多供应商适配、模型路由、Token 计费、Rerank 或 OpenAI 协议兼容经验。  
5\. 有 Slack、Telegram、微信等消息平台 Bot 或 Gateway 开发经验。  
6\. 熟悉 Kubernetes、OpenTelemetry、Prometheus、Langfuse 等云原生与可观测技术。  
7\. 有 Agent 评测、上下文压缩、长期记忆、任务规划或工具选择优化经验。  
8\. 有开源项目贡献、复杂 Monorepo 维护或 AI 编程基础设施研发经验。
