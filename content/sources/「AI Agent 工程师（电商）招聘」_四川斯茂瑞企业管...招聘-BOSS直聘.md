AI Agent 工来自BOSS直聘程师（偏后端）  
关于我们  
Saparo 是面向北美市场的 AI Agent 消费助手，致力于通过⼈⼯智能重新定义消费者的购物体验。  
我们基于 OpenClaw、Codex、Claude Code 等前沿 AI 技术，打造能够⾃主理解用户需求、执行全⽹商品搜索与比价、规划最优采购方案，并完成下单操作的智能消费 Agent，让 AI 真正从信息助手进化为能够执行任务的个人消费代理。  
公司采用 AI-Native 的组织与研发模式，推行扁平化管理和异步书面协作，以实际产出和业务数据为核心考核标准。我们鼓励团队深度使用 AI 编程工具，通过自动化提升研发效率，专注海外 C 端 AI 产品创新与业务增长。  
职位概述  
我们正在寻找一位具备 AI Agent 项目开发经验和扎实后端工程能力的工程师，参与 Saparo 核心 AI Agent 系统的设计、开发与持续迭代。  
你将负责构建能够自主完成复杂消费任务的 AI Agent，包括任务规划、工具调用、工作流编排、上下文管理，以及与商品搜索、比价、订单和支付等业务系统的深度集成。  
我们希望你不仅熟悉大语言模型与 Agent 技术，也具备将 AI 能力转化为真实产品的工程实践经验，能够独立解决 Agent 在实际业务场景中的稳定性、准确性、执行效率和成本问题。  
本岗位直接向 CEO 汇报，深度参与公司核心 AI 产品的技术架构设计与研发，是 Saparo AI Agent 产品落地的关键技术角色。  
核心职责  
AI Agent 系统设计与开发  
\* 参与设计和开发 Saparo 核心 AI Agent 系统，实现用户需求理解、任务规划、工具调用和自动化执行。  
\* 基于主流大模型及 Agent 开发框架，构建具备多步骤推理、任务执行和状态管理能力的智能体。  
\* 设计 Agent 工作流与任务调度机制，支持复杂任务的分解、执行、异常处理与结果反馈。  
\* 持续优化 Agent 的任务完成率、执行效率、稳定性及模型调用成本。  
LLM 应用开发与模型集成  
\* 负责大语言模型 API 的集成与应用开发，结合业务场景优化模型调用策略。  
\* 设计和优化 Prompt、Context Engineering、Tool Calling、Structured Output 等核心机制。  
\* 结合业务需求，探索 RAG、Memory、多 Agent 协作等技术方案，并推动实际应用。  
\* 建立 Agent 效果评估与测试机制，持续提升复杂任务的执行成功率与结果可靠性。  
AI Agent 工具链与业务系统集成  
\* 开发和维护 Agent 所需的工具接口，打通商品搜索、价格查询、订单管理、支付等业务能力。  
\* 设计 Agent 与后端服务之间的通信、任务调度和数据交互机制。  
\* 探索浏览器自动化、网页交互及第三方 API 集成，使 Agent 能够在真实互联网环境中完成购物任务。  
\* 针对外部系统的不确定性，设计可靠的异常处理、重试和人工确认机制。  
后端系统开发与架构设计  
\* 参与核心后端服务的架构设计与开发，支撑 AI Agent 产品的业务运行。  
\* 负责用户、商品、订单、支付等业务模块的接口开发与系统集成。  
\* 设计和优化数据库结构、缓存及异步任务处理机制，保障系统性能与可扩展性。  
\* 负责核心服务的部署、监控和线上问题排查，持续提升系统稳定性。  
AI-Native 研发与产品迭代  
\* 深度使用 Claude Code、Codex、Cursor 等 AI 编程工具，提高研发效率。  
\* 与产品团队协作，快速完成 AI Agent 产品原型开发、技术验证和功能迭代。  
\* 跟踪 AI Agent 技术生态发展，评估新模型、新框架及新工具在实际业务中的应用价值。  
\* 以真实用户任务完成率和业务结果为导向，持续推动产品能力提升。

\* 主导或深度参与过真实用户使用的 AI Agent 产品研发。

海外 C 端产品与电商经验
