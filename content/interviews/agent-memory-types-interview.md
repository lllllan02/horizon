[[agent-memory|Agent 记忆]]就是把过去的信息保存下来，后续需要时再取用，让对话能接着进行，也减少跨会话重复询问。一般可以先按使用范围分为短期记忆和长期记忆。

1. **短期记忆**：保留同一个会话中的消息、工具调用与结果，以及当前任务状态。实现时，可以按会话 ID 把[[history-storage|交互记录]]逐条写进数据库，或者追加到 JSONL 文件，每行一个 JSON 对象；任务状态也可以通过检查点保存。后续读回该会话的历史和状态，再由[[agent-context|上下文管理]]选取、裁剪或压缩，组成本轮模型输入。这里的「短期」指会话范围，即使存进数据库、重启后还能恢复，也仍然属于短期记忆；本轮输入只包含当前选用的部分。

2. **长期记忆**：跨会话复用的用户偏好、已确认事实、长期要求和任务经验。实现时，可以从交互中提取值得保留的内容，去重或更新后，按用户、项目等范围存进文件或数据库。使用时，已知偏好可以直接按 key 读取；需要找相关经验时，可以做关键词或向量检索。向量方案通常保留原文及元数据，再用 embedding 建索引，检索后把相关内容加入本轮上下文。**向量数据库是可选实现，长期记忆也可以用普通数据库或文件。**

如果面试官按[[langgraph-memory#内容怎样组织？|记忆内容]]继续追问，还可以分为语义记忆（事实与偏好，可用用户档案或事实条目保存）、情景记忆（过去的事件与执行经历，可保存轨迹或案例）和程序性记忆（做事的方法与规则，可用提示词或规则文件保存）。这是另一种分类维度，与短期、长期的划分不冲突。
