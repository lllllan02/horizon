[[agent-memory#整体使用|长期记忆]]是**跨会话保存、供后续反复使用的信息**，让 Agent 减少重复确认，并沿用已有的背景和要求。常见内容包括：

- **用户方面**：习惯、偏好、长期要求和明确纠正，例如希望怎样回答、哪些事不要做。
- **项目方面**：[[agent-memory-content-sources#Claude Code：补足代码之外的协作背景|持续目标、约束和已确认的决定]]等后续仍会用到的背景。

提取时注意两个要求：

1. **有依据**：来自用户明确表达或已经确认的事实，不把模型猜测当成记忆。
2. **范围明确**：说明适用于哪个用户、项目或场景，以及有效时间。只在最近几天或某个项目中成立的要求，不能推广为永久、通用的要求。
