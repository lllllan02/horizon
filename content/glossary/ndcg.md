**NDCG@K 衡量前 K 条结果的排序与理想排序有多接近**：K 是只检查前多少条，理想排序由人工标注的相关性等级决定。

它对「把相关材料排前面」敏感：相关性越高的片段贡献越大，同一片段放得越靠后、贡献越小；再用实际排序得分除以理想排序得分，得到 0 到 1 之间的 NDCG，越接近 1 越好。

例：人工把三个片段标成「直接回答」「部分帮助」「无关」，把「直接回答」排在前面，就比把「无关」排在前面得分更高。

评测时要统一相关性等级、计算方式和 K，没有相关证据的问题单独处理。**NDCG 高不等于回答所需的信息齐全**——它衡量标注相关性的排序表现，不检查不同条件或例外是否都被覆盖。指标定义与实现差异可核对 [[rag-evaluation-docs|检索指标导读]]。

常见计算取 `DCG@K = Σ gain(rel_i) / log2(i+1)`，再除以该查询全部标注相关项理想排序的 `IDCG@K`，不能只用当前系统已召回的候选归一化。gain 可取相关等级本身或指数增益，比较时必须一致。非负增益且 IDCG 大于 0 时，结果在 0 到 1 之间；IDCG 为 0 的查询需明确跳过或记 0 等约定。
