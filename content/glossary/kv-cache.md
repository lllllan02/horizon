**KV Cache 是大模型推理时，保存已处理 Token 在各注意力层中产生的键（Key）和值（Value）向量的缓存。** 它们是模型计算出的中间数据；K 用来参与匹配相关信息，V 提供被加权汇总的信息。

模型生成下一个 Token 时，需要利用前文。对于常见的因果注意力模型，新增后文不会改变前面位置已经算好的 K、V，因此可以保存并重复使用，避免每生成一个 Token 都重算前文的这些数据。新位置仍需计算，并读取历史 K、V；机制依据见 [[kv-cache-sources#逐 Token 生成时缓存什么|Hugging Face 的解释]]。

在此基础上，推理服务还可以保留请求的 KV，让后续请求复用**相同前缀**的计算。例如先处理「固定说明＋问题甲」，再处理「固定说明＋问题乙」，可以复用固定说明对应的部分。这需要服务支持前缀缓存，而且缓存仍可用；[[kv-cache-sources#跨请求复用省掉哪段计算|vLLM 的说明]]区分了这与单次生成中的复用。

KV Cache **保存中间计算结果，回答仍需重新生成**。前缀复用也不按语义相似度匹配；文字中间一段相同，不能据此假定它可以独立复用。缓存还会占用内存或显存，并随保留的上下文增长。
