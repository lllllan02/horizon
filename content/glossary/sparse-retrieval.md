**稀疏召回（Sparse Retrieval）是利用多数维度为零的文本表示来匹配查询与文档、筛选候选的一类检索方法。** 常见的传统做法依靠词项匹配，适合查询与资料共享具体术语、名称或错误码的场景。

以词袋为例，词表中的每个词占一个位置，文本在对应位置记录词频。一份简化表示可以写成：

```text
词表：  [苹果, 数据库, 消息, 旅游, 消费, ……]
文档：  [ 0,     0,    2,    0,    1, ……]
```

实际词表可能很大，一篇文档只用到其中一小部分词，所以大多数位置为零，这就是「稀疏」的含义。上例只演示表示方式，不是 BM25 的评分公式；实际检索通常使用倒排索引，按词项定位文档，无需存储或逐一比较完整的零值列表。

[[bm25|BM25]]是常见的传统稀疏召回评分方法：根据查询词在文档中的匹配情况，结合词项区分度、词频与文档长度排序。查询「消息重复消费」时，它容易找到用词相近的资料；若资料只写「事件幂等处理」，没有同义词扩展等处理就可能漏检。

「稀疏」描述的是表示中非零值的分布，不能直接等同于「不理解语义」。[[rag-retrieval-ranking#稀疏与稠密描述什么？|官方稀疏编码说明]]指出，SPLADE 等学习型稀疏模型也能表达语义。它与[[dense-retrieval|稠密召回]]的严格区别在于表示方式，而不只是能否匹配同义表达。
