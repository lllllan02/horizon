Lewis 等人在 2020 年研究的是：在知识密集任务中，怎样结合生成模型的**「参数知识与可更换的外部索引」**。本文节选论文的方法、实验设计与适用边界，未复现实验。

## 检索怎样参与生成？

论文把 DPR 检索器与 BART 生成器连接起来：检索器对输入检索 Wikipedia 片段，生成器同时读取输入和片段。文档作为隐变量，训练目标对 top-k 文档的生成概率加权求和；这比应用层简单拼接片段多了一层联合训练。

RAG-Sequence 在整段输出层面混合各文档的概率；RAG-Token 在每个输出 token 层面混合，因此不同位置可依赖不同文档。后者不等于每生成一个字都重新访问数据库。训练更新查询编码器与生成器，文档编码器和索引保持固定，避免持续重建索引。

## 实验支持什么结论？

作者在开放域问答、事实验证和生成任务中比较纯参数模型与检索增强模型，并通过冻结检索器、替换检索方法等消融观察各部分贡献。论文支持“外部知识可帮助这些任务”，没有证明任意检索都能提高答案质量。

工程中可借鉴外部知识与生成分工，但**「日常 RAG 不要求复现 DPR、BART 或联合训练」**。现代 API 拼接式 RAG 与论文的概率模型应分开理解。具体方法与消融定位在原文第 2、4 节。
